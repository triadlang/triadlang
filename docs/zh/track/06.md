# 06 — 错误：优雅地打破

## `try` / `catch` / `finally`

```
  try {
      在此冒险
  } catch 错误 {
      倒下就倒在此（错误带消息）
  } finally {
      永远经过这里
  }
```

```tri
try {
    throw "boom";
} catch e {
    print("抓住: " + str(e));
} finally {
    print("永远执行");
}
```

`▸ 输出`

```text
抓住: boom
永远执行
```

`throw` 扔任何值（文本、数字、字典）。

## `assert`：锁住你的确定

```tri
fn chu(a, b) {
    assert b != 0;
    return a / b;
}

print(chu(10, 2));   // 5.0
// chu(10, 0) 以断言错误中止
```

`assert` 是可执行文档：条件失败，程序停在那里并指向该行。

## `match`：按值选择

```tri
let v = 2;

match v {
    case 1 {
        print("yi");
    }
    case 2 {
        print("er");
    }
}
// ▸ er
```

每个 `case` 测一个值；对应块执行。

## 应急三件套

```
  坏了？ ──────► throw "原因"
  可能坏？ ────► try / catch
  绝不能？ ────► assert 条件
```

✎ 试试：`fn gen(x)`，`x < 0` 就扔，否则返回
`math.sqrt(x)`（需要 `import math;`）。
