# 04 — 集合：列表和字典

## 列表：顺序重要

```tri
let shu = [10, 20, 30];

print(shu[0]);      // 10（索引从 0 开始）
print(len(shu));    // 3

shu.push(40);       // 加到末尾
print(shu);         // [10, 20, 30, 40]
```

遍历：

```tri
let shu = [10, 20, 30, 40];
for n in shu {
    print(n * 2);
}
// ▸ 20 40 60 80
```

## 字典：名字重要

```tri
let ren = {"mingzi": "Ana", "nianling": 30};

print(ren["mingzi"]);   // Ana
ren["chengshi"] = "SP"; // 创建新键
print(ren["chengshi"]); // SP

del ren["nianling"];    // 删除键
print(ren);             // {"mingzi": "Ana", "chengshi": "SP"}
```

遍历键：

```tri
let ren = {"mingzi": "Ana", "chengshi": "SP"};
for jian in ren {
    print(str(jian) + ": " + str(ren[jian]));
}
```

## 文本是技巧包（`string`）

```tri
import string;

print(string.upper("triad"));              // TRIAD
print(string.split("hi dev triad"));       // ["hi", "dev", "triad"]
print(string.join("-", ["a", "b"]));       // a-b
```

## JSON 进出（`json`）

```tri
import json;

let shuju = {"mingzi": "TriadLang", "n": 1};
let wenben = json.stringify(shuju);
print(wenben);                   // {"mingzi": "TriadLang", "n": 1}

let hui = json.parse(wenben);
print(hui["mingzi"]);            // TriadLang
```

## 速查图

```
  要顺序 ──► 列表 [...] + push + 索引
  要名字 ──► 字典 {...} + ["键"]
  要文本 ──► string.split/join/upper/...
  要交换 ──► json.stringify / json.parse
```
