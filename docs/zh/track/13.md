# 13 — 本地：C、内核及更远

## 三层，一门语言

```
  ┌─────────────────────────────────┐
  │  .tri 程序（你在这里）           │
  ├─────────────────────────────────┤
  │  native/c   C 运行时 + 检查器    │  ./native/c/triad check f.tri
  ├─────────────────────────────────┤
  │  native/kernel  裸机启动        │  asm + ld → kernel.bin
  └─────────────────────────────────┘
```

## C 那边

`native/c/` 有 C 运行时（`libtriad_rt`）、命令行和主机测试
（regex、自微分形状、AES、求解器一致性）。今天 C 版 `triad`
检查 `.tri`（词法 + 语法 + 类型检查）：

```sh
./native/c/triad check examples/basic/hello.tri
```

构建和主机测试走 `make -C native/c` 目标。

## 内核那边

`native/kernel/` 是 x86 裸机内核：启动和描述符表汇编、
链接脚本、`kernel.bin` 镜像、主机测试。这是 TRIAD OS
方向 — 基底即操作系统。
