# 07 — 模块：导入世界

## 三种形状

```tri
import math;                    // 整个模块
import math as m;               // 起别名
from math import sqrt, pi;      // 只要需要的
```

## 核心标准库（永远可用）

```
  math         sqrt sin cos log exp floor ceil pi e min max
  random       random randint choice seed shuffle uniform
  string       split join replace lower upper strip
  json         parse stringify
  fs           read_text write_text exists listdir join tempdir
  time         now sleep
  collections  len range enumerate sorted zip map filter…
  datetime     日期和时间
  regex        正则表达式
  plot         图表（triad.plot 是同一个）
  io           print input
```

合在一起的例子：

```tri
import math;
import random;

random.seed(0);
print(math.sqrt(25.0));       // 5.0
print(random.randint(1, 10)); // 7（seed 0 时）
```

## 文件（`fs`）

```tri
import fs;

let lujing = fs.join(fs.tempdir(), "hi.txt");
fs.write_text(lujing, "Hello file!");
print(fs.read_text(lujing));   // Hello file!
print(fs.exists(lujing));      // true
```

## 自己的模块

文件 `util.tri`（文件名须与导入名一致）：

```tri
fn double(n) {
    return n * 2;
}
```

同一文件夹的 `app.tri`：

```tri
import util;

print(util.double(21));   // 42
```

## 包（大项目）

```sh
./triad init woapp         # 创建项目
./triad install           # 安装依赖
./triad publish           # 发布到本地仓库
./triad list              # 列出已安装
```

依赖住在 `triad_modules/`。
