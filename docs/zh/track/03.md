# 03 — 函数

## 基本 `fn`

```
  fn 名字(参数) {
      ...
      return 值;
  }
```

```tri
fn jia(a, b) {
    return a + b;
}

print(jia(2, 3));   // 5
```

没有 `return`，函数返回 `none`。

## 默认值

```tri
fn mifang(di, zhi=2) {
    return di ** zhi;
}

print(mifang(3));      // 9
print(mifang(2, 10));  // 1024
```

## `*args` 和 `**kwargs`：来多少收多少

```tri
fn quanbu_qiuhe(*shuzi) {
    let s = 0;
    for n in shuzi {
        s = s + n;
    }
    return s;
}
print(quanbu_qiuhe(1, 2, 3, 4));   // 10

fn xianshi(**xuanxiang) {
    for jian in xuanxiang {
        print(str(jian) + " = " + str(xuanxiang[jian]));
    }
}
xianshi(yanse="lan", daxiao=42);
// ▸ yanse = lan / daxiao = 42
```

## 递归可以

```tri
fn fib(n) {
    if n <= 1 {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

print(fib(10));   // 55
```

## `yield`：分段交付的函数

```tri
fn jishu() {
    yield 1;
    yield 2;
    yield 3;
}

for v in jishu() {
    print(v);
}
// ▸ 1 2 3
```

每个 `yield` 暂停并交出一个值；`for` 从停处继续。
