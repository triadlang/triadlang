# 00 — 欢迎

## 30 秒了解 TriadLang

```
   .tri ──► ./triad ──► 结果
    │           │
    │           ├── 直接运行 (run)
    │           ├── 类型检查 (check)
    │           ├── 内含真正的 Python (import numpy、flask…)
    │           └── 内含真正的物理 (求解器、SAT、量子比特)
    │
    └── 或物理 DSL：reg / ring / OBSERVE
```

TriadLang 是一门完整的编程语言（变量、函数、类、错误、
模块），有两个不寻常的门：它导入真正的 Python 生态，
并且内置积分场动力学引擎（TRIAD 求解器），能解 SAT、
量子线路这类问题。

## 检查一切正常

```sh
./triad doctor
```

`▸ 输出` — 环境报告（Python、依赖、本地部分）。

如果缺东西，向导安装会修好：

```sh
./triad setup
```

## 第一次运行（2 分钟）

文件 `hi.tri`：

```tri
print("Hello from TriadLang");
```

```sh
./triad run hi.tri
```

`▸ 输出`

```text
Hello from TriadLang
```

成功了？你已经会运行 TriadLang 了。剩下的是语言。

## 你会一直用的两个检查

```sh
./triad check hi.tri     # 只查类型，不执行
./triad fmt hi.tri       # 格式化文件
```
