**A programming language where execution is field evolution.**

Most languages run instructions. TriadLang runs physics.
You write code, the runtime evolves a continuous field forward in time,
and your observables fall out of what the field arrived at on its own.

```
your .tri file  ──▶  field evolves (P1 + P2 + P3)  ──▶  measurements
```
