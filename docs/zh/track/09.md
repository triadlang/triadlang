# 09 — Python：生态是你的

TriadLang 导入真正的 Python 包。同名，同对象。

## numpy 原样到来

```tri
import numpy;

let a = numpy.array([1, 2, 3, 4, 5]);
print(numpy.sum(a));    // array(15, dtype=int64)
print(numpy.mean(a));   // array(3.0, dtype=float64)
```

from 导入也可以：

```tri
from numpy import sum, mean;

print(sum([10, 20, 30]));   // array(60, dtype=int64)
```

## flask 服务，click 点击

```tri
import flask;

let app = flask.Flask("triad_test");
print(app.name);   // triad_test
```

```tri
import click;

print("click works");   // 绑定加载
```

解物理并回 JSON 的路由（见
`examples/interop/flask_solver.tri`）：用
`app.add_url_rule` 定义，用 `flask.jsonify` 回答。

测试客户端不用服务器即可证明：

```tri
// examples/interop/boundary_flask_testclient.tri
// ▸ status code = 200, json status = ok, json value = 42
```

## 默认安全，你说了才 unsafe

```
  ./triad run app.tri              安全：只许祝福过的导入
  ./triad run app.tri --unsafe     完整 Python，风险自负
```

安全模式允许：`triad math random statistics json itertools
functools collections re datetime fs io string time hash csv logging
threading net os subprocess socket numpy click flask`。

名单之外需要 `--unsafe` — 否则导入失败并打印允许名单。

## 互操作地图

```
  数值计算 ──► import numpy / triad.ntri
  网页接口 ──► import flask（+ 测试客户端）
  命令行 ────► import click
  文件进程 ──► import os（安全）/ subprocess（安全）
  其余一切 ──► --unsafe
```

`examples/interop/` 里九个可运行例子 — 全绿。
