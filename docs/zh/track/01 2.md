# 01 — 第一步

## 变量：`let` 和 `const`

```tri
let x = 10;
let mingzi = "Triad";
let huoyue = true;
const PI2 = 3.14159 * 2;

print(x + 20);      // 30
print(mingzi);      // Triad
print(huoyue);      // true
print(PI2);         // 6.28318
```

- `let` 创建可变变量：`x = 99;` 可以。
- `const` 创建常量：修改是错误。
- 分号结束句子。永远。

## 你 99% 时间用的四个类型

```
  10            3.14           "文本"          true / false / none
  └── Int      └── Float      └── String       └── Bool (none = 空)
```

```tri
print(10 + 3.14);            // 数字加数字可以
print("hi " + "dev");        // 文本加文本拼接
print("n = " + str(42));     // 数字用 str() 变文本
```

`▸ 输出`

```text
13.14
hi dev
n = 42
```

## `print` 显示、`str` 转换、`type` 揭示

```tri
print(str(3.14));     // "3.14"
print(type(10));   // <class 'int'>
print(type("hi"));   // <class 'str'>
```
