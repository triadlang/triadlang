# 05 — 类型和类

## `type`：简单数据模具

```tri
type Ren {
    mingzi: String;
    nianling: Int;
}

let p = Ren(mingzi="Ana", nianling=30);
print(p.mingzi);    // Ana
print(p.nianling);  // 30
```

`type` 是纯结构：带类型的字段，没有行为。

## `class`：数据 + 行为

```
  class 名字 {
      fn __init__(self, ...) { ... }   // 在此出生
      fn 方法(self, ...) { ... }       // 在此生活
  }
```

```tri
class Zhanghu {
    fn __init__(self, huxing) {
        self.huxing = huxing;
        self.yue = 0;
    }

    fn cun(self, jine) {
        self.yue = self.yue + jine;
    }
}

let c = Zhanghu("Ana");
c.cun(100);
print(c.yue);   // 100
```

- `self` 是实例自己，永远第一个参数。
- `__init__` 在创建时运行。

## 继承：`inherits`

```tri
class Dongwu {
    fn __init__(self, mingzi) {
        self.mingzi = mingzi;
    }
    fn jiao(self) {
        return "...";
    }
}

class Mao inherits Dongwu {
    fn jiao(self) {
        return "miau";
    }
}

let g = Mao("Tom");
print(g.mingzi + " jiao " + g.jiao());
// ▸ Tom jiao miau
```

`Mao` 继承 `mingzi`，改写 `jiao` — 其余来自父类。

## 何时用哪个

```
  只存字段 ────► type
  存 + 做事 ───► class
  复用 + 变化 ─► inherits
```
