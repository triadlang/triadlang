# 02 — 控制：判断与重复

## `if` / `elif` / `else`

```tri
let fenshu = 7;

if fenshu >= 7 {
    print("通过");
} elif fenshu >= 4 {
    print("补考");
} else {
    print("挂科");
}
```

`▸ 输出`：`通过`

比较：`==` `!=` `<` `<=` `>` `>=`。
逻辑：`and`、`or`、`not`。

```tri
let nianling = 20;
let youqingjian = true;

if nianling >= 18 and youqingjian {
    print("请进");
}

if not false {
    print("真");
}
```

## `for`：两种形状

```tri
// 1. 计数
for i in range(3) {
    print(i);
}
// ▸ 0 1 2

// 2. 遍历
for mingzi in ["ana", "bia"] {
    print("hi " + mingzi);
}
// ▸ hi ana / hi bia
```

`range(5)` → 0..4。`range(2, 8)` → 2..7。

## `while`、`break`、`continue`

```tri
let x = 0;
while x < 10 {
    x = x + 1;
    if x == 3 {
        continue;   // 跳过 3
    }
    if x == 6 {
        break;      // 停在 6
    }
    print(x);
}
// ▸ 1 2 4 5
```

## f-string：文本里算数

```tri
let zong = 250;
print(f"总和 0..99 = {zong}");
print(f"双倍 = {zong * 2}");
```

`▸ 输出`

```text
总和 0..99 = 250
双倍 = 500
```

`{ }` 里的一切当场计算。
